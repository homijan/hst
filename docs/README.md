# Euler fluid Hamiltonian

## Hamiltonian in 1D 
$`\begin{equation}
H(\rho, v, \varepsilon) = \int \left( \frac{1}{2}\rho(x) v(x)^2 + \rho(x) \varepsilon(x) \right) dV
\end{equation}`$

## Hamilton-Jacobi in 1D

$`\begin{eqution}
\partial_t S(\rho, t) + H(\rho, v, \varepsilon, t) = 0
\end{equation}`$
